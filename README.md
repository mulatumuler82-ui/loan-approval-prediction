# Loan Approval Prediction Model

Supervised machine learning classification pipeline that evaluates financial
risk metrics to predict loan approval, comparing **Logistic Regression**,
**Decision Trees** and **Random Forests**.

**Stack:** Python · Scikit-Learn · Pandas · Matplotlib

## Run it

```bash
pip install -r requirements.txt
python generate_data.py   # creates data/loan_data.csv (skip if using real data)
python train.py           # trains, tunes, compares, saves best model + reports
python predict.py         # scores a sample applicant
```

## Pipeline

1. **Feature engineering**: TotalIncome, LogTotalIncome, EMI, IncomeToEMI
2. **Preprocessing**: median / most-frequent imputation, scaling, one-hot encoding
   (all inside a `Pipeline`, so there is no train/test leakage)
3. **Models**: each tuned with 5-fold stratified `GridSearchCV` (scoring = F1),
   `class_weight="balanced"` to handle the approved/rejected imbalance
4. **Evaluation**: accuracy, precision, recall, F1, ROC-AUC on a held-out 20% split
5. **Outputs**: `models/best_model.joblib`, `reports/metrics.json`,
   `reports/model_comparison.csv`, ROC curves, confusion matrix, feature importances

## Using the real dataset

`data/loan_data.csv` is **synthetic** (generated by `generate_data.py`) because the
original dataset wasn't available. To use the Kaggle "Loan Prediction" data, save
it as `data/loan_data.csv` (same column names: Gender, Married, Dependents,
Education, Self_Employed, ApplicantIncome, CoapplicantIncome, LoanAmount,
Loan_Amount_Term, Credit_History, Property_Area, Loan_Status) and rerun `train.py`.
Expect lower scores (~80%) on real data than on the synthetic set.
